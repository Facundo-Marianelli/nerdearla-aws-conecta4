# Conecta 4 - Juego para Dos Jugadores

Un juego clásico de Conecta 4 implementado en HTML, CSS y JavaScript puro para dos jugadores.

## 🎮 Descripción del Juego

Conecta 4 es un juego de estrategia donde dos jugadores alternan turnos dejando caer fichas de colores en una cuadrícula vertical de 7 columnas por 6 filas. El objetivo es ser el primero en formar una línea de cuatro fichas consecutivas horizontal, vertical o diagonalmente.

## 🚀 Características

- **Interfaz intuitiva**: Diseño limpio y moderno con efectos visuales
- **Jugabilidad fluida**: Detección automática de victorias y empates
- **Animaciones**: Efectos visuales para las fichas ganadoras
- **Responsive**: Se adapta a diferentes tamaños de pantalla
- **Reinicio rápido**: Botón para comenzar una nueva partida

## 🎯 Cómo Jugar

1. **Inicio**: El Jugador 1 (fichas rojas) comienza la partida
2. **Turno**: Haz clic en cualquier columna para dejar caer tu ficha
3. **Objetivo**: Conecta 4 fichas de tu color en línea (horizontal, vertical o diagonal)
4. **Victoria**: El primer jugador en conectar 4 fichas gana
5. **Empate**: Si se llena el tablero sin ganador, es empate
6. **Nuevo juego**: Usa el botón "Nuevo Juego" para reiniciar

## 🛠️ Instalación y Uso

1. **Descarga** todos los archivos en una carpeta
2. **Abre** el archivo `index.html` en tu navegador web
3. **¡Juega!** No requiere instalación adicional
